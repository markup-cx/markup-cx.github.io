MARKUP IN. CLEAN HTML OUT.

One small converter.
More than one syntax.

Markup++ is a dependency-free C++17 library and CLI for converting Markdown, AsciiDoc and reStructuredText to HTML. The first development checkpoint starts with Markdown.

Get started View source
terminal
$ markup README.md -o README.html
# or stream a fragment
$ markup README.md > fragment.html
01

Native and focused

A compact library with no runtime dependencies and a thin command-line interface.

02

Built to embed

String-in, string-out conversion behind a narrow API, ready for future Nift integration.

03

Honest formats

Markdown works now. AsciiDoc and reStructuredText fail clearly until their converters land.

04

Safe file behavior

Atomic output, permission preservation, and refusal to overwrite input files or output symlinks.

LIBRARY FIRST

A clean boundary for tools.

Markup++ does not know about project graphs, templates or files. Give it markup and a format; receive HTML or a controlled error.

std::string html, error;
markup::convert(
    markup::Format::Markdown,
    source, html, error);
