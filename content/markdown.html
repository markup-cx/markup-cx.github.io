FORMAT 01

Markdown, without inflated claims.

The first checkpoint covers the syntax people use in ordinary project documentation. Full CommonMark conformance remains deliberate future work.

Blocks

  • ATX and Setext headings
  • Paragraphs and breaks
  • Block quotes
  • Ordered and unordered lists
  • Task lists
  • Fenced and indented code
  • Thematic breaks
  • Pipe tables and alignment

Inline

  • Emphasis and strong emphasis
  • Strikethrough
  • Code spans
  • Links and images
  • URL and email autolinks
  • Entities and escapes
  • Optional raw HTML

Not claimed yet

  • Complete CommonMark conformance
  • Nested and loose list fidelity
  • Reference links and footnotes
  • Full delimiter-run semantics
  • Complete HTML block rules
  • Heading identifiers

INPUT

# Release notes

Markup++ keeps **conversion** small.

- native C++17
- fragment or standalone HTML
- future Nift embedding

OUTPUT

<h1>Release notes</h1>
<p>Markup++ keeps <strong>conversion</strong> small.</p>
<ul>
  <li>native C++17</li>
  <li>fragment or standalone HTML</li>
  <li>future Nift embedding</li>
</ul>
