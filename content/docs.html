Convert your first document.

Build with any C++17 compiler, then send HTML to stdout or an explicit output file.

On this pageBuildCLILibrary APISafety

Build

git clone https://github.com/nift-dev/markup.git
cd markup
make
make test

The only build requirement is a C++17 compiler and Make. The resulting executable is markup.

CLI

markup README.md
markup README.md -o README.html
markup --standalone --title "Project notes" notes.md -o notes.html
printf '# Hello\n' | markup --format markdown -

Output is an HTML fragment by default. Use --standalone for a minimal HTML5 document. Input from stdin requires --format because there is no filename extension to inspect.

Library API

#include <markup/Markup.h>

std::string html;
std::string error;
markup::Options options;

bool ok = markup::convert(
    markup::Format::Markdown,
    source,
    html,
    error,
    options);

The public API performs no file IO and owns no global mutable state. That separation is what will let Nift embed Markup++ without coupling the converter to Nift internals.

Raw HTML and safe mode

Raw HTML passes through by default, as users commonly expect from Markdown. --safe escapes raw HTML and rejects active URL schemes. It is a conservative rendering option, not a complete sanitizer for hostile content.

markup --safe comments.md -o comments.html
